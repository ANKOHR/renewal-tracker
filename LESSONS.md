# Lessons for KOML

The domain needs explicit reference dates and separate currency/cadence groups. An overdue declared date is a reminder to check the record, not evidence of debt. Cancelled services can retain historical dates without becoming alerts.

The controlled fixture validates the assumption that deterministic classification and exact decimal grouping can reproduce hand-planted counts and amounts with zero false positives. It does not validate usefulness, completeness of a manually entered renewal list, time saved, or demand. These remain unmeasured until the real-use window.

One evidence-based implementation improvement: an adversarial test changes the snapshot total while leaving the records intact. Recomputing and reconciling the snapshot during report rendering rejects that forged total instead of displaying it. This addresses stale or edited summary values with evidence from a planted failure, and does not claim protection against a wholly forged snapshot.

Operating rule for future builds: define the calendar boundaries and monetary units first, plant an independent oracle, then prove the output changes when source facts change. Keep synthetic acceptance separate from real adoption evidence.
